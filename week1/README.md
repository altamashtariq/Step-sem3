## How to run

Compile and run one file:

```bash
javac Problem1_ExamHallSeatDuplicationChecker.java
java Problem1_ExamHallSeatDuplicationChecker
```

Or compile everything at once and run each in turn:

```bash
javac *.java
java Problem1_ExamHallSeatDuplicationChecker
java Problem2_TypingSpeedTestAccuracyChecker
java Problem3_TrafficSignalStreakAnalyzer
java Problem4_WarehouseInventoryBalancer
java Problem5_MovieReviewWordLengthProfiler
```

- All five outputs were compiled and run against the sample input/output tables in the assignment PDF — they match exactly.
